FOOTJRI — УСТАНОВКА НА ГЛАВНЫЙ ЭКРАН ANDROID

ВАЖНО: PWA устанавливается с опубликованного сайта по HTTPS. Само по себе открытие index.html как скачанного файла не включает установку PWA и service worker.

ЧТО ЗАГРУЗИТЬ В РЕПОЗИТОРИЙ GITHUB PAGES
1. Распакуй архив.
2. Открой репозиторий FootJRI на GitHub.
3. Загрузи содержимое папки FootJRI_PWA в корень репозитория, сохраняя структуру:
   index.html
   manifest.webmanifest
   sw.js
   icons/icon-192.png
   icons/icon-512.png
4. Замени старый index.html новой версией, если готов перейти на этот вариант.
5. Дождись завершения GitHub Pages deployment.
6. Открой https://faratdaerak-cloud.github.io/FootJRI/ в Chrome.
7. Меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».
8. Запусти FootJRI с новой иконки.

ОБНОВЛЕНИЯ
После публикации новых файлов открой приложение с интернетом и перезапусти его. Новая версия должна загружаться через network-first навигацию; обновление service worker может занять некоторое время. Для крупных изменений логики лучше увеличить CACHE_VERSION в sw.js (например, v1 -> v2), чтобы сбросить старый кэш.

ОГРАНИЧЕНИЯ
- Это всё ещё веб-приложение, не APK.
- Онлайн-аккаунты, серверные сохранения, торговля и настоящий онлайн-рейтинг этим архивом не добавляются.
- Монеты и коллекция хранятся локально в браузере; не очищай данные сайта, если хочешь их сохранить.
- Архив включает последнюю подготовленную локальную версию FootJRI_fixed_local.html в качестве index.html. Проверь её на сайте перед тем, как считать релиз готовым.


ВАЖНО ПРИ ЗАГРУЗКЕ НА GITHUB:
- Распакуй ZIP.
- Открой папку FootJRI_PWA.
- Загружай СОДЕРЖИМОЕ этой папки в корень репозитория, а не саму папку.
- В архиве есть index.html. Если подтвердить замену существующего index.html на GitHub, опубликованная версия сайта заменится версией из этого архива.
- Если хочешь сохранить точную текущую опубликованную версию, не заменяй index.html без предварительной проверки.
